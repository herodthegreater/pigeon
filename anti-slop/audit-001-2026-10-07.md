# antislop audit 001 · 2026-10-07

Scope: the v1 teaching site in `site/` on branch `v1-teaching-site` at `03aaf51` (same as `origin/v1-teaching-site`).
Method: code inspection of every page, layout, token file and UI module, with contrast ratios computed from `site/src/styles/tokens.css`. Nothing has been changed.

Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW.
Pick the numbers you want fixed. Numbers you do not name are left alone.

Paths are relative to `site/`.

## Where the site is already clean

No em dashes in visible text, no buzzwords, no generic CTAs, no emoji, no gradients (apart from the pigeon's iridescent neck), no glass, glow, background grid, icon library or infinite animation. There is a global `:focus-visible` outline and a `prefers-reduced-motion` rule. Every control has a real handler, and the "500 photos" claim matches `public/testset/testset.json`. The mascot, a hand-built SVG bird whose species tracks how much the model has shrunk and whose body tracks its accuracy, is a real identity motif and the strongest thing on the site.

## HIGH (Hard Gate)

1. **The Coop has no error state when loading fails.** If the model or test set fails to load, `engine.ready` rejects and the module throws at `pages/coop/index.astro:183`. The page then stays on "Loading Pigeon…" / "Starting the engine…" forever. The fetches in `lib/engine/model.ts:42-44` and `lib/engine/testset.ts:26,36` never check `r.ok`, and there is no fallback when Worker or WebAssembly support is missing. *R-27*
2. **A scoring failure after the page is ready is invisible.** `lib/engine/client.ts:38` sends worker errors to `console.error` only, so the status line stays on "Scoring on 100 photos…". *R-27*
3. **The loading state never moves.** The worker sends progress during the baseline run with id 0 (`lib/engine/worker.ts:64,84`), but `Engine.route` drops it because `current` is null (`lib/engine/client.ts:52-53`). The bar stays at 0% and the status text doesn't change for the whole first load. *R-27*
4. **Home copy describes pages that don't exist yet as if they do.** `pages/index.astro:31-33` says "Twelve short lessons…" and "Every technique that matters in 2026… with code for your own models". The "Start Flight School" CTA (`:14`) goes to a page marked "Coming next" that has no lessons, and the Field Guide has no code. *R-38, C-5*
5. **`--faint` text fails contrast.** It measures 2.64:1 on paper and 2.84:1 on card in light mode, and 4.05:1 and 3.72:1 in dark mode. It's used for the 0.68rem photo credits (`pages/coop/index.astro:151`). *R-25*
6. **The "Starving" label fails contrast.** `--warn` on card measures 4.36:1, used at 0.7rem (`pages/coop/index.astro:72`). *R-25*
7. **Teal text and the main CTA sit just under AA.** `--teal` on paper, and paper-colored text on the teal "Open the Coop" button, both measure 4.49:1 (`pages/index.astro:43`). *R-25*
8. **The mascot loses its outline in dark mode.** `--bird-line #0d1113` on dark card `#182227` measures 1.17:1. The species colors are fixed hex values in `lib/ui/mascot.ts:36-69` and don't adapt to the theme, so the dark-mode bird is a dark shape on a dark card. *R-34*
9. **Tap targets are below 44px.** Measured heights: "Remove" step about 24px (`pages/coop/index.astro:105`), preset and add-step buttons about 33px (`:95`), segmented-control options about 30px (`:114`), nav links about 30px (`layouts/Base.astro:38`), photo credit links about 17px (`:151`). *R-03*
10. **The Pareto chart's details are mouse-only.** Point details live only in SVG `<title>` tooltips (`lib/ui/pareto.ts:49`), and the chart is a `role="img"` with a one-line label and no data alternative (`:52`). Keyboard and touch users can't read which recipe each dot is. *R-32*
11. **Preset explanations are mouse-only, and presets give no feedback.** Each preset's explanation sits only in a `title` attribute (`lib/ui/recipe.ts:95`). Preset buttons show no selected or `aria-pressed` state. *R-32, R-26*
12. **The favicon is the default Astro logo** (`public/favicon.svg`). It's an asset nobody chose for Pigeon. Tell me what the icon should be, or I'll use a plain placeholder. *R-23*
13. **Two unlinked dev pages ship publicly and break on phones.** `pages/aviary.astro` and `pages/lab.astro` build into `dist/` but have no viewport meta tag, and aviary uses a fixed 4-column grid. Either exclude them from the build or make them responsive. *R-03*
14. **The quick estimate looks like a final result.** The 100-photo estimate fills the metric strip and changes the bird, and only the small status line says it's provisional (`pages/coop/index.astro:236-238`). The numbers need a visible "estimate" marker until the 500-photo result arrives. *R-38*
15. **There is no written design direction yet.** There's no `DESIGN.md` and no declared dials, so every Purpose-Gate and liveliness judgment below is provisional until it exists. This is in progress: your answers to the direction questions become `DESIGN.md`. *R-37*

## MEDIUM (Purpose-Gate)

16. **The best-result callout has a colored left stripe.** `.best` has a 3px magenta left border on magenta wash (`pages/coop/index.astro:87`). If it marks the "smallest working model" state, write that reason down. If it's decoration, remove it. *R-01, R-31*
17. **Small labels are uppercase mono with wide tracking.** `.label` (`styles/tokens.css:69-71`) and `.metric dt` (`pages/coop/index.astro:82`) use 0.7rem mono, uppercase, 0.12em tracking. They appear as the home eyebrow above the H1, as "Coming next", and as section labels in the recipe editor. Either write a reason (for example, a lab-notebook voice) or set them in sentence case. *R-06*
18. **The three home cards have equal weight.** `pages/index.astro:30-34` gives Flight School, The Coop and Field Guide identical cards, but only the Coop exists. The hierarchy should show that. *R-14*
19. **The aria-live region covers the whole Coop hero.** `aria-live="polite"` on the entire hero (`pages/coop/index.astro:6`) makes screen readers announce the status every 25 images, plus every metric and mascot change. Narrow it to one summary line that updates when scoring finishes. *C-4, R-32*
20. **The `data-theme` hooks are dead.** `styles/tokens.css:37-52` has `[data-theme]` selectors that nothing sets, and the two dark palettes are written out twice. Depending on your theme answer, either build the toggle or remove the hooks and keep the dark palette in one place. *R-21, R-34*
21. **Typefaces have no written reason yet.** Newsreader, Public Sans and IBM Plex Mono are not default AI picks, but none of them has a reason written down. Pending `DESIGN.md`. *R-06, R-31*

## LOW (Quality Locks)

22. **Colors outside the tokens.** Detection boxes use `#3fd1b4` (`pages/coop/index.astro:144`), the heatmap uses `rgb(214,66,150)` (`lib/ui/specimens.ts:61`), and there are more literals in `lib/ui/mascot.ts:108,216,221`. They should become tokens so the active palette stays at teal, magenta and neutrals. *R-29*
23. **Font sizes are off the type scale.** Eleven sizes sit outside the `--step` scale (0.68, 0.7, 0.75, 0.78, 0.85, 0.88, 0.9, 0.93, 0.95, 1.05, 1.1rem), mostly in `pages/coop/index.astro`. *R-20, R-31*
24. **There is no spacing scale.** All padding and gaps are ad-hoc pixel values, so section rhythm happens by accident rather than by choice. *R-05*
25. **The placeholder pages are dead ends.** `pages/school/index.astro:22` says "the Coop is open" as plain text instead of a link. Neither placeholder page gives a next step beyond the nav, and both are styled inline. *R-05, C-2*
26. **A threshold is typed twice.** "≥ 90% accuracy and ≥ 75% pointing" is hard-coded at `pages/coop/index.astro:25,227` instead of reading `WORKS` (`lib/ui/mascot.ts:84`). The text will drift if the threshold changes. *C-1*
27. **The home CTAs have no hover state** (`.go`, `.alt` in `pages/index.astro`). *R-20*
