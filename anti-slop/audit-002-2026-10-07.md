# antislop audit 002 · 2026-10-07

Scope: the combined site as merged to `main` in `7f8c474`: the lab served under `/lab/` (`lab/web/static/`, its markdown content, and `lab/REPORT.md`), plus the home page and nav changes from the merge. The Coop's remaining items are in audit 001 (15 to 27) and are not repeated here.
Method: code inspection, contrast computed from `lab/web/static/style.css`, and checks on the production preview (`astro preview`) at desktop and 375px, light and dark, with a keyboard pass. Nothing has been changed.

Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW.
Pick the numbers you want fixed. Numbers you do not name are left alone.

Paths are relative to the repo root.

## Where the lab is already clean

No gradients, glow, blur, shadows, background patterns, animations, icon library or emoji. No marketing words, no generic CTAs, no em dashes in the 43 method pages, the app, or the lessons. Every control has a handler. Every number on the home page (43 methods, 28 experiments, 10 lessons, per-family counts) is computed from the data. Keyboard focus is visible (2px accent outline, confirmed with real Tab presses). Markdown tables, code blocks and the experiment table all scroll inside their containers, and nothing overflows the page at 375px. The theme toggle works and persists. Run results show real measured numbers, and the in-browser Python run was confirmed on the production build.

## The big one

1. **The site has two identities.** Clicking "Lab" in the nav drops the visitor into a different product: system sans instead of Newsreader and Public Sans, a blue accent (`#2a6fd0`) instead of teal and magenta, white cards with 6px radius and pill badges instead of ruled panels on sage paper, a different header with its own five-item nav and a "Dark" button the main site doesn't have, a different favicon (a blue circle), and no bird anywhere. The lab's brand link goes to `#/`, and there is no link back to Pigeon, so the only way home is the browser's back button. Swap the logo and the lab could belong to any product. This is the merge's cost and the reason phase 2 exists; until then it fails R-20 and R-30-adjacent "could be anything" test, and the nav item is a one-way door. (`lab/web/static/index.html:12-20`, `style.css:2-28`) *R-20, R-24, R-29, C-1*. The fix is phase 2 (move the lab's pages into the site, under the v1 look). A cheap interim fix: a one-line bar above the lab's header that links back to Pigeon, and the Pigeon favicon.

## HIGH (Hard Gate)

2. **Tertiary text fails contrast in light mode.** `--ink-3 #85827b` measures 3.68:1 on the background and 3.83:1 on cards, and `--tok-com` (code comments) 3.45:1 on the code background. `--ink-3` carries `.muted` lines, the status line, breadcrumbs, the family-card counts, field help text and chart axis text (`style.css:7,21`). Dark mode passes (5.5:1). *R-25*
3. **Chart series colors are near-identical in luminance.** The four series run 1.1:1 to 2.0:1 against each other in light mode and 1.07:1 to 1.26:1 in dark, and `--s4` (`#eda100`) is 2.2:1 on white. The lines and dots are told apart by hue only; a legend swatch at 2px radius cannot carry that. (`style.css:24`, `app.js:201-230`) *R-25*
4. **Tap targets under 44px.** Measured at 375px on the production build: nav links 34px, the theme button 32px, the Run button 40px, range sliders 16px, checkboxes 13px. TOC links are about 27px. (`style.css:79-83,141-148`) *R-03*
5. **The header's nav is a horizontal scroll strip with the end cut off.** At 375px the fourth item shows as "Buil" and the fifth ("Results") is off-screen, with the scrollbar hidden and no fade or cue that more exists (`style.css:79`, `#nav { overflow-x: auto; scrollbar-width: none }`). *R-03*
6. **The lesson editor traps Tab.** Tab inserts four spaces and is prevented; only Shift+Tab leaves the textarea (`app.js:392-396`). A keyboard user who tabs into the editor can't tab forward out of it, and nothing says so. Escape should release it, and the behavior should be announced. *R-32*
7. **The theme button's accessible name contradicts its visible label.** `aria-label="Toggle dark mode"` is fixed while the text reads "Dark" or "Light" (`index.html:20`), and there's no `aria-pressed`. Once clicked there is no way back to "follow the system" (`app.js:74-87`), and the theme is applied by the end-of-body script, so a stored theme can flash the wrong colors on load. *R-32, R-34*
8. **"Python is ready." stays on screen during the first training run.** The worker's last status message replaces the "Training…" line (`app.js:348`, `worker.js:40`), so for the whole first run the page says ready while the button says "Running…". There's no progress, no cancel and no timeout on runs. *R-27*
9. **"Show solution" has no error handling.** A failed fetch is an unhandled rejection: the confirm dialog closes and nothing happens (`app.js:405-408`). And if Pyodide fails to initialise, the rejected promise is cached, so every later run fails until reload, with no message saying so (`worker.js:12-13`). *R-27*
10. **Every fetch failure on a method, lesson or experiment page says "Not found."** A dropped connection or a 500 renders the same copy as a bad URL (`app.js:306,370,437`). *R-27*
11. **Chart tooltips are mouse-only.** Point details are `mouseover` tooltips on SVG circles that aren't focusable (`app.js:187-196`); the run-result table beside the chart carries the numbers, so this is partly covered, but the per-point values in multi-series charts aren't in the table. *R-32*
12. **Five em dashes in `lab/REPORT.md`,** which renders as prose on `#/results` (lines 43, 151, 152, 239, 264). Agent-written text, so in scope. *R-02*
13. **`#/results` has two H1s.** The page renders `<h1>Simulation results</h1>` and then REPORT.md's own `# What the simulations say` (`app.js:428`, `REPORT.md:1`). Home skips from h1 to h3 (`app.js:233-255`). *R-32, C-4*
14. **The page title never changes.** `document.title` is always "pigeon lab" across 43 method pages, 10 lessons and 28 experiments (`app.js`, no assignment). Tabs, history and screen readers all read the same name. *R-32*
15. **No `prefers-reduced-motion` handling for the TOC's smooth scroll** (`app.js:333`). The only motion on the page, but unconditional. *R-19, C-4*

## MEDIUM (Purpose-Gate)

16. **Pill badges with a dot.** `.pill` is a 99px capsule with a `::before` dot (`style.css:127-133`). The pills mark real states (runnable, cockpit, reference, passed), so the badge is earned; the dot marks nothing the color and text don't already say, and the capsule shape is the only pill on a site whose other controls are 4px-radius rectangles. Keep the label, drop the dot, match the site's radius. *R-09, R-11, R-31*
17. **Typeface chosen by default.** `--sans` is the system stack with Inter and Roboto as fallbacks, and `--mono` is `ui-monospace` (`style.css:27-28`). No reason is written; it will be replaced by the site's Newsreader, Public Sans and IBM Plex Mono in phase 2. *R-06*
18. **Blue accent chosen by default.** `#2a6fd0` has no written reason and conflicts with the site's teal and magenta. The syntax-highlight palette (`--tok-*`) and chart series add six more hues, so the lab alone runs well past 2 to 3 core colors + 1 accent. *R-01, R-29*
19. **The `.note` left stripe.** `border-left: 2px solid var(--line-2)` (`style.css:159`) marks run notes. It's a quote-style rule rather than a colored stripe, so it's borderline; write the reason or drop it. *R-01, R-31*
20. **The "How to read a method page" legend on home.** Three rows explaining the three pills (`app.js:251-254`). It exists because the pills need explaining; once the pills carry plain words ("Runs here", "Runs in the cockpit", "Reference"), the section can go. *C-3*

## LOW (Quality Locks)

21. **Twelve near-duplicate small font sizes** (.76 to .95rem, plus 11px, 12.5px and 13.5px) with no scale (`style.css`). The site's `--step` scale should replace them in phase 2. *R-20*
22. **No spacing scale.** Padding and gaps are ad hoc rem values (`style.css:76-113`). *R-05*
23. **The dark palette is written out twice** (`style.css:33-38` and `42-48`), same as the site's tokens file (audit 001 item 20). *C-1*
24. **A hardcoded figure background** `#fcfcfb` that doesn't change in dark mode (`style.css:187`), so figures sit in a white box on the dark theme. *R-34*
25. **Nav labels differ from their page titles.** "Language models" opens "Language-model methods"; "Vision" opens "Vision / detector (pigeon)" (`index.html:15-16`, `methods.py:38-51`). The current item is styled with a class but not `aria-current`. *R-24, R-32*
26. **Lesson pager links don't name the target.** "Previous lesson" / "Next lesson" with no title (`app.js:387`). *R-15*
27. **Identical alt text on sibling figures.** Every figure of one experiment gets the experiment title as `alt` (`app.js:328,444`), and figures aren't lazy-loaded. *R-32*
28. **Home page lede counts experiments but doesn't link to them.** "the results of 28 simulation experiments" is plain text; Results is reachable only from the nav (`app.js:244-245`). *R-24*
