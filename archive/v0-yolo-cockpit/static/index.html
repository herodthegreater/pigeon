How to reverse-train a model — guide & glossary

What is reverse training?

Normal training grows a model from noise. Reverse training runs it backward: you start from a capable, fully-trained model and remove from it — precision, channels, whole layers — until only the one capability you need survives. The result is a smaller, faster model that does one thing well and nothing else. The loop is always cut → measure → regrow → repeat.

The three ways to cut

🎚️ Precision — store each weight in fewer bits. Cheap and graceful; shrinks the file size. Nearly free down to 8-bit. Start here.

✂️ Structure — remove whole channels. The only lever that makes the model faster. Powerful but a cliff: cut too much without regrowing and accuracy falls to zero. Cut by value.

🌱 Regrow — fine-tune after cutting. This heals the wound and is mandatory after a structural cut — it's what makes reverse training work instead of just breaking the model.

Using this tool

1. Scan (Structure) to reveal which stages are safe to cut.  2. Take the suggested cut, or open the details and cut by hand.  3. Measure the real accuracy hit.  4. Regrow to recover.  5. Export the smaller model. The scoreboard tracks mAP, size, and compute the whole time.

Glossary

Weight / parameter
a single number the model learned.
Channel / filter
a bundle of weights that detects one kind of feature; removing one shrinks the layer and speeds it up.
Stage (L0–L22)
a block of the network — one column in the grid.
Quantization (bits)
fewer bits per weight (16→8→4…). Smaller file, same shape. Degrades gracefully.
Pruning
removing capacity. Structural = whole channels (real speedup). Masking = zeroing them (safe live preview — identical accuracy, no speed change until Export).
Sensitivity
how much mAP drops when you cut a stage. Low = redundant (safe); high = load-bearing (avoid).
Value = FLOP ÷ sensitivity
the payoff of a cut: much compute saved, little accuracy lost. Cut high-value stages first.
FLOPs
compute per image — the portable measure of speed (trust it over laptop latency).
mAP@50
detection accuracy: how well it finds birds (higher is better).
The cliff
structural pruning kills accuracy suddenly, unlike quantization's gentle slope — which is why you must regrow.
Fine-tune / regrow
retraining the wounded model to recover the accuracy a cut cost.
Export
bake your cuts into a real, smaller model file on disk.

Options
▸ Principles of reverse training
  1. Precision is cheap, structure is a cliff. Fewer bits degrade gently; removing channels can kill the model in one cut.
  2. Cut where the FLOPs are. A few stages hold most of the compute; trimming tiny ones does nothing.
  3. Cut where sensitivity is low. Scan first — value = FLOP ÷ sensitivity.
  4. Cut a little, regrow, repeat. Small cuts + fine-tune beat one big cut. Re-scan each round — the map shifts.
  5. Trust FLOPs, not laptop latency. The compute/size drop is the portable prize for edge hardware.
